01 · PROBLEM

Turn a timetable into a graph.

Each course is a vertex. A shared-student conflict creates an edge. Each exam slot is a colour. A valid timetable is a proper graph colouring.

◈

Input

Conflict graph + fixed number of available colours (time slots).

◎

Constraint

Adjacent courses can never receive the same colour.

✦

Goal

Find a valid colouring with as few practical time slots as possible.

02 · ALGORITHMS

Two ways to search the solution space.

The assignment requires a plain method and an improved backtracking method using a pruning heuristic such as Most-Constrained-Vertex or Forward Checking. fileciteturn0file1L39-L39

Plain Backtracking

06 · COMPLEXITY

Why pruning changes practical performance.

The assignment identifies O(kⁿ) as the worst-case time complexity for plain backtracking on n courses and k colours. The pruning version does not remove the exponential worst-case class in general, but it can shrink the effective search tree dramatically on structured instances.
