01 · PROBLEM

Turn a timetable into a graph.

Each course is a vertex. A shared-student conflict creates an edge. Each exam slot is a colour. A valid timetable is a proper graph colouring.

◈

Input

Conflict graph + fixed number of available colours (time slots).

◎

Constraint

Adjacent courses can never receive the same colour.

✦

Goal

Find a valid colouring with as few practical time slots as possible.

02 · ALGORITHMS

Two ways to search the solution space.

The assignment compares plain Backtracking with a pruning-enhanced method using a constraint-based heuristic.

A · BASELINEO(kⁿ)

Plain Backtracking

Assign vertices one at a time. Try colours in order, detect conflicts, and backtrack when a choice fails.

01 choose vertex02 try colour03 check conflict04 backtrack
B · PRUNEDSEARCH ↓

Pruning-Enhanced

Choose the most constrained unassigned course first and remove unavailable colours, reducing unnecessary exploration.

01 score vertices02 pick hardest03 prune colours04 recurse

06 · COMPLEXITY

Why pruning changes practical performance.

The plain backtracking search has worst-case time O(kⁿ). Pruning does not remove the general exponential worst-case class, but it can reduce the effective search tree on structured instances.

T(n,k) ≈ k × k × … × k = kⁿ
